{# templates/base.html 모든 페이지가 공통으로 상속하는 뼈대 템플릿. 네비게이션 바와 flash 메시지 영역을 담당하며, 자식 템플릿은 {% block content %} 부분만 채워 넣으면 된다. #} {# 자식 템플릿에서 {% block title %} 을 덮어쓰지 않으면 아래 기본값이 쓰인다. #} {% block title %}Flask Blueprint 샘플{% endblock %} {# 스타일시트 연결. - CSS 파일은 app/static/ 안에 둔다. Flask 가 이 폴더를 /static/... 경로로 자동 공개한다. - 경로를 "/static/css/style.css" 라고 직접 쓰지 않고 url_for 를 쓰는 이유는 링크에 url_for 를 쓰는 이유와 같다. 앱을 다른 경로 아래에 붙여도 주소가 알아서 맞춰진다. - 이 한 줄이 base.html 에만 있으면 된다. 나머지 템플릿은 전부 base.html 을 상속하므로 자동으로 같은 스타일을 물려받는다. #}
{# 링크는 절대 "/auth/login" 처럼 직접 쓰지 않고 url_for("블루프린트명.함수명") 으로 만든다. - url_for("main.index") -> "/" - url_for("auth.login") -> "/auth/login" (url_prefix 가 자동으로 반영된다) - url_for("auth.logout") -> "/auth/logout" 이렇게 하면 app.py 에서 url_prefix 를 바꿔도 템플릿은 손댈 필요가 없다. #} 홈 {# session 은 템플릿 안에서 별도 전달 없이 바로 쓸 수 있다(Flask 가 기본 제공). #} {% if session.get('username') %} {# 에이전트 페이지는 로그인해야 쓸 수 있으므로 로그인했을 때만 메뉴에 보여준다. #} 대시보드 AI 에이전트 이벤트 {# 관리자 메뉴는 관리자에게만 보여준다. 단, '메뉴를 숨기는 것'은 보안이 아니다. 실제 차단은 admin 블루프린트의 before_request 가 하고, 여기서는 보이지 않게만 할 뿐이다. #} {% if session.get('username') in config['ADMIN_USERS'] %} 관리자 {% endif %} 로그아웃 {{ session.get('username') }}님 {% else %} 로그인 {% endif %}
{# flash() 로 넣어둔 메시지를 꺼내서 출력한다. with_categories=true 를 주면 (카테고리, 메시지) 튜플로 받아 스타일을 구분할 수 있다. 한 번 꺼내면 세션에서 사라지므로 새로고침하면 더 이상 보이지 않는다. #} {% with messages = get_flashed_messages(with_categories=true) %} {% if messages %} {% for category, message in messages %}
{{ message }}
{% endfor %} {% endif %} {% endwith %} {# 자식 템플릿(index.html, login.html)이 채워 넣을 자리 #} {% block content %}{% endblock %}
